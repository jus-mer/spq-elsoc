Subjective social status (SSS) models

This section describes the processing and integration into multilevel models of a series of variables created to expand the measurement of subjective social status

SSS Mobility

Then, subjective social mobility was operationalized as the difference between respondents’ perceived current social status and their family-of-origin status, with positive values indicating upward mobility and negative values indicating downward mobility. Two alternative measures were considered: (mov_dir) a direct difference score, calculated at each wave by subtracting family-of-origin status from respondents’ current status; and (mov_og) a difference score using the respondent’s mean family-of-origin status across waves as a fixed reference point, thereby reducing the influence of wave-to-wave measurement noise in the family-of-origin item.

Code 
df_study1 <- df_study1 %>%
  group_by(idencuesta) %>%
  mutate(mov_dir      = ess - ess_og,
         mov_dir_mean = mean(mov_dir),
         mov_dir_cwc  = mov_dir - mov_dir_mean,
         mov_og       = ess - ess_og_mean,
         mov_og_mean  = mean(mov_og),
         mov_og_cwc   = mov_og - mov_og_mean) %>%
  ungroup()
Code

SSS Mobility expectations

Expected mobility for the next generation (mov_exp) was operationalized as the difference between the perceived subjective social status of the respondent’s children and the respondent’s own status, so that positive values indicate a higher expectation of upward mobility for their children. As with the other measures, it was decomposed into its between-person (mean) and within-person (centered) components.

Code 
df_study1 <- df_study1 %>%
  mutate(mov_exp = ess_hijos - ess) %>%
  group_by(idencuesta) %>%
  mutate(mov_exp_mean = mean(mov_exp),
         mov_exp_cwc  = mov_exp - mov_exp_mean) %>%
  ungroup()

SSS Intergenerational mobility

Expected intergenerational mobility (mov_inter) was operationalized as the perceived subjective social status of the respondent’s children minus the respondent’s own status and minus the family-of-origin status, so that positive values indicate a higher expectation of intergenerational mobility. It was decomposed into its between-person (mean) and within-person (centered) components.

Code 
df_study1 <- df_study1 %>%
  mutate(mov_inter = ess_hijos - ess - ess_og) %>%
  group_by(idencuesta) %>%
  mutate(mov_inter_mean = mean(mov_inter),
         mov_inter_cwc  = mov_inter - mov_inter_mean) %>%
  ungroup()

SSS Slope

Individual trajectories in subjective social status were estimated using ordinary least squares (OLS) regression of perceived social status on calendar year, yielding an individual-specific slope expressed in status points per year. Positive slopes indicate an upward trajectory in subjective social status, whereas negative slopes indicate a downward trajectory. The measure was calculated only for respondents with at least four observed waves.

Code 
min_waves <- 4

ess_slope <- df_study1 %>%
  mutate(year = as.numeric(as.character(ola))) %>%
  group_by(idencuesta) %>%
  summarise(n_waves   = sum(!is.na(ess)),
            ess_slope = if (n_waves >= min_waves) unname(coef(lm(ess ~ year))[2]) else NA_real_,
            .groups = "drop") %>%
  select(idencuesta, ess_slope)

df_study1 <- df_study1 %>%
  left_join(ess_slope, by = "idencuesta")

Marginal effects: within-person SSS by between-person SSS

Marginal effect of within-person subjective social status (ess_cwc) on the MJP index at different levels of between-person status (ess_mean: -1 SD, mean and +1 SD). Since the model is linear, the average marginal effect equals the conditional slope, b(ess_cwc) + b(ess_cwc x ess_mean) * ess_mean, and does not depend on the other covariates.

Code 
b <- fixef(m58)
V <- as.matrix(vcov(m58))
int_name <- intersect(c("ess_cwc:ess_mean", "ess_mean:ess_cwc"), names(b))

# be_vals defined in the predicted-values chunk above
ame <- map_dfr(names(be_vals), function(lv) {
  x  <- be_vals[[lv]]
  w  <- setNames(c(1, x), c("ess_cwc", int_name))   # gradient of the slope
  est <- sum(w * b[names(w)])
  se  <- sqrt(as.numeric(t(w) %*% V[names(w), names(w)] %*% w))
  tibble(be = lv, ess_mean = x, ame = est, lwr = est - 1.96 * se, upr = est + 1.96 * se)
}) %>%
  mutate(be = factor(be, levels = names(be_vals)))

ggplot(ame, aes(x = be, y = ame, ymin = lwr, ymax = upr, colour = be)) +
  geom_hline(yintercept = 0, linetype = "dashed", colour = "grey40") +
  geom_pointrange(linewidth = 0.8, size = 0.6) +
  scale_colour_manual(values = met.brewer("Hiroshige", 3), guide = "none") +
  labs(x = "Between-person SSS", y = "Marginal effect of within-person SSS") +
  theme_minimal(base_size = 11) +
